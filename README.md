# Zengin Flow (全銀データ変換ツール)

企業の経理・財務実務者が、安全かつ迅速に全銀フォーマット（全銀協規定振込データ・固定長120バイト・Shift_JIS）を作成するための完全ローカル完結型Webアプリケーションです。

## 特徴

- **完全ローカル完結（高セキュリティ）**:
  - 外部サーバーやクラウドへのデータ送信は一切行いません。
  - すべてのデータ処理・Shift_JISファイル生成はブラウザ内のJavaScriptメモリ上で完結します。
  - オフライン環境（通信切断状態）でも動作します。
- **2つの作成フロー**:
  - **CSVファイルから作成**: 会計ソフト（freee、マネーフォワード、弥生など）の支払一覧CSVをドラッグ＆ドロップで一括変換。列自動判別機能付き。
  - **画面入力で作成**: スプレッドシート形式のテーブルで直接手入力。ドラッグ＆ドロップによる行並び替えや、複数行を選択してのブロック一括移動に対応。
- **全銀協標準仕様準拠**:
  - 1レコード120バイト固定長、改行CRLF、Shift_JISエンコード出力。
  - 半角カナ・英数大文字・許容記号への自動文字正規化。
  - ヘッダーレコード（1）、データレコード（2）、トレーラレコード（8）、エンドレコード（9）の完全生成。
  - 各行の120バイト固定長生データプレビュー＆リアルタイムバリデーション。
- **自社口座情報の端末内保持**:
  - 依頼人コードや会社名義はブラウザのlocalStorageに安全に保持され、次回起動時に入力を省略できます。

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS
- encoding-japanese (Shift_JISエンコーディング)
- PapaParse (CSV解析)
- Lucide React (アイコン)

## ローカル開発手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# 本番用ビルド
npm run build
```
