# Zengin Flow (全銀データ変換ツール)

企業の経理・財務実務者が、安全かつ迅速に全銀フォーマット（全銀協規定振込データ・固定長120バイト・Shift_JIS）を作成するための**完全ローカル完結型Webアプリケーション**です。

---

## 🔒 セキュリティと安心の設計

- **完全ローカル完結（外部送信ゼロ）**:
  - アップロードしたCSVデータや入力した口座番号・振込金額などは、**すべてお使いのブラウザ内（メモリ上）でのみ処理**されます。
  - 外部のサーバーやクラウドAPIへの通信は一切発生しません。
  - ページを開いた後は、**インターネット接続を切断（オフライン環境）しても全機能が動作**します。
- **自社口座情報のブラウザ内保持**:
  - 依頼人コードや会社名義は、お使いの端末のブラウザ内（localStorage）にのみ安全に保存され、外部に漏洩することはありません。

---

## ✨ 主な機能

1. **初期モード選択**:
   - **「CSVファイルから作成」**（会計ソフト等のCSVを一括取込）
   - **「画面入力で作成」**（スプレッドシート形式の画面で直接手入力）
2. **CSV取り込みと自動判定（フローA）**:
   - 会計ソフト（freee、マネーフォワード、弥生など）から出力した支払CSVをドラッグ＆ドロップ。
   - Shift_JIS / UTF-8 の文字コードを自動判別。
   - 銀行コード・支店コード・口座種別・口座番号・受取人名・金額の各列を自動マッピング（手動変更も可能）。
   - 全銀協標準CSV（行区分1, 2, 8...）のダイレクトインポートにも対応。
3. **直感的なテーブル手入力（フローB）**:
   - スプレッドシート形式で支払先や金額をスムーズに入力・編集。
   - **ドラッグ＆ドロップによる行の並び替え**に対応。
   - チェックボックスによる**複数選択＆ブロック一括移動**、一括複製・一括削除に対応（Shiftキーでの範囲選択も可能）。
4. **全銀協標準仕様への自動準拠**:
   - 1レコード120バイト固定長、改行コードCRLF、Shift_JISエンコード。
   - 濁音・半濁音を含む全角カタカナ・英数字を、全銀規定の半角カナ・英数大文字へ自動正規化。
   - ヘッダー（1）、データ（2）、トレーラ（8）、エンド（9）レコードを完全生成。
5. **確認画面＆エクスポート**:
   - 振込総額・合計件数の自動サマリー表示。
   - リアルタイムバリデーション（必須漏れ・桁数・文字種エラー検知）。
   - **120バイト固定長生データプレビュー**（銀行に送られる実データを目視確認可能）。
   - **Shift_JIS形式テキスト（`.txt` / `.dat`）のダウンロード**、UTF-8ダウンロード、クリップボードコピーに対応。
   - サンプルCSVのワンクリックダウンロード機能。

## 👥 最も簡単な使い方・配布方法

本ツールはサーバーやデータベースを必要としない**完全クライアントサイド（ブラウザ完結・単一ファイル）**で動作します。

### 【超簡単】フォルダ内の「全銀データ作成ツール.html」をダブルクリックするだけ！

1. プロジェクトフォルダ直下にある **`全銀データ作成ツール.html`** をダブルクリックします。
2. お使いのブラウザ（Microsoft Edge, Google Chrome 等）が開き、アプリが即座に起動します。
3. Node.jsやサーバー起動、インターネット接続は不要です。　社内チャットやメールでこのHTMLファイル1つを渡すだけで誰でも利用可能です。

※なお、直下の `index.html` は開発者用の設定ファイルです。誤って開いた場合でも案内画面が表示され、ワンクリックでツールを起動できます。

#### パターンB：GitHubからZIPダウンロードして渡す（ソースコード共有）
1. GitHubリポジトリ（`https://github.com/yoshiki2024/zengin_data`）を開きます。
2. 緑色の **「Code」** ボタンをクリックし、**「Download ZIP」** を選択します。
3. ダウンロードされたZIPファイルを相手に渡します。

---

### 【方法2】GitHub PagesでWebサイトとして共有する（相手にダウンロードさせない方法）

相手にファイルをダウンロード・解凍させず、**「URLをクリックするだけ」**でブラウザから直接使ってもらいたい場合に最適な方法です。

> **🔒 Web公開してもセキュリティは安全？**  
> 本ツールは外部サーバーへのデータ通信を一切行わず、100%利用者のブラウザ（ローカル）でのみ処理されます。Webサイトとして公開されていても、利用者が入力した振込データや口座情報がサーバーや第三者に送信されることはありません。

#### 公開URLの設定手順（リポジトリ管理者が初回に1回行うだけ）：
1. GitHubの [yoshiki2024/zengin_data](https://github.com/yoshiki2024/zengin_data) リポジトリを開きます。
2. 画面上部の **「Settings（設定）」** タブをクリックします。
3. 左サイドバーの **「Pages」** を選択します。
4. **「Build and deployment」** の下の **「Source」** で **「GitHub Actions」** を選択し、一覧から **「Static HTML」** または Vite 用のテンプレートを選択して保存（またはブランチ指定）します。
5. デプロイ完了後、Pages画面上部に専用の公開URLが表示されます：
   ```
   https://yoshiki2024.github.io/zengin_data/
   ```
6. **受け取った側の使い方**:
   - 社内やチームのメンバーに上記URLを共有するだけです。
   - PC、Mac、タブレット問わず、ブラウザを開くだけで即座に全銀データを作成・ダウンロードできます。

---

### 【方法3】Git Clone を使う（開発者向け）

社内のシステム開発者やエンジニアがソースコードを取得し、カスタマイズや機能追加を行う場合の手順です。

#### 開発環境のセットアップ手順：
```bash
# 1. リポジトリをクローン
git clone https://github.com/yoshiki2024/zengin_data.git

# 2. プロジェクトディレクトリへ移動
cd zengin_data

# 3. 依存パッケージのインストール
npm install

# 4. ローカル開発サーバーの起動 (HMR有効)
npm run dev
# -> ブラウザで http://localhost:5173 を開きます

# 5. 本番用ビルド（静的ファイル生成）
npm run build
# -> dist/ ディレクトリに最適化された静的ファイル一式が出力されます
```
